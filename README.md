# 🍧 Delícias da Duda - Landing Page

Landing page moderna, atrativa e responsiva desenvolvida para o negócio **Delícias da Duda**, especializada na divulgação e venda de sacolés gourmet artesanais da região.

O projeto foi estruturado para encantar visualmente o cliente, apresentar o catálogo de sabores, destacar a prova social (depoimentos), facilitar a localização dos pontos de retirada e converter visitantes em clientes através de integração direta com o WhatsApp.

---

## 🚀 Tecnologias Utilizadas

* **Front-End:** HTML5, CSS3, JavaScript (ES6+)
* **Estilização:** Tailwind CSS (ou CSS customizado focado em design limpo e responsivo)
* **Hospedagem / Deploy:** Vercel

---

## 🎯 Principais Funcionalidades

* **Hero Section Atravente:** Apresentação de impacto com chamada para ação (*CTA*) direcionada para pedidos rápidos.
* **Vitrine de Sabores:** Seção visual detalhando as opções de sacolés gourmet oferecidas.
* **Depoimentos e Prova Social:** Exibição de feedbacks reais de clientes para gerar autoridade e confiança.
* **Pontos de Retirada:** Mapa e fotos informando os locais físicos onde os produtos podem ser adquiridos ou retirados.
* **Seção "Seja Nosso Parceiro":** Formulário interativo para captação de novos parceiros com envio automático dos dados estruturados via WhatsApp.
* **Design Responsivo:** Totalmente adaptado para navegação fluida em smartphones, tablets e computadores.
